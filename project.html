FOV CRM 2.0

A client management app for a recruitment agency. I first built it in C# during my IT apprenticeship from a brief I was set. Now I've rebuilt it from the ground up as a web app you can try right here.

The brief

A recruitment agency needed one place to keep their client contacts and see how each account was doing. Staff had to be able to add new clients, find existing ones quickly, update their details, and rate each company's risk as Green, Orange or Red and its status as Active or Inactive.

Version 2.0: what I changed

Looking back at my apprenticeship code with a few years' experience, I could see what I'd do differently. So I rebuilt it.

Version 1 (2022)

  • Search boxes put the user's text straight into the SQL query, so it was open to SQL injection
  • The update and delete queries had syntax errors, so editing didn't work reliably
  • People and companies were saved in two separate tables with nothing linking them
  • No checks on emails or phone numbers before saving
  • Three separate windows to switch between
  • Only ran on Windows with Microsoft Access installed

Version 2.0 (2026)

  • Searching is plain text matching, and everything a user types is shown as text, never run as code
  • Add, edit and delete all work, with an undo button if you delete by mistake
  • Each client is one record: contact, company, risk and status together
  • Checks for valid emails, UK mobile numbers and duplicate clients, with clear error messages
  • One screen: live summary counts, a search across every field, filters, sortable columns, and an activity log for each client
  • Runs in any browser, works on phones, supports dark mode, and exports to CSV

Why it still matters

This project taught me how applications store and work with data, and gave me the coding background I now use for PowerShell scripting in my support role. Coming back to it after working in IT security, the biggest lesson was clear: never trust what a user types. That's the first thing I fixed in version 2.0.
